ngopi.yuk adalah website company profile untuk sebuah kedai kopi yang menyediakan berbagai pilihan kopi dan minuman lainnya. Website ini dibuat untuk memperkenalkan ngopi.yuk kepada pengunjung, mulai dari menu yang tersedia, daftar harga, hingga cerita di balik kedai kopi ini.

Melalui website ini, pengunjung dapat mengenal ngopi.yuk sebagai tempat untuk menikmati kopi, bersantai, dan menghabiskan waktu bersama teman maupun keluarga.

Fitur
-Beranda (Home)
  Menampilkan halaman utama yang memperkenalkan ngopi.yuk beserta suasana dan keunggulannya.

-Tentang Kami (About)  
  Berisi cerita, sejarah singkat, visi, dan misi ngopi.yuk.

-Menu (service diganti menu)
  Menampilkan berbagai pilihan menu kopi dan minuman lainnya beserta harganya.

-Galeri (Gallery)
  Menampilkan foto menu, suasana kedai, dan berbagai aktivitas di ngopi.yuk.

-Kontak (Contact)
  Menyediakan informasi alamat, media sosial, dan formulir pesan untuk pengunjung.

Cara menjalankan

1. Buka folder proyek melalui Visual Studio Code.
2. Buka terminal pada folder proyek.
3. Jalankan website menggunakan perintah:
   npm run dev
4. Buka alamat lokal yang muncul di terminal pada browser.

Dengan adanya website ngopi.yuk, diharapkan pengunjung dapat lebih mudah mengenal kedai kopi ini, melihat pilihan menu dan harga, serta mengetahui cerita dan informasi seputar ngopi.yuk.
